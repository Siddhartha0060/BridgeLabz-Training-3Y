Responsive CSS Cheat Sheet

Filters

Filters change the appearance of images.

filter: grayscale(100%);

Media Queries

Media queries apply CSS according to screen size.

@media (max-width: 700px)

Responsive Design

Responsive design works on different devices.

width: 100%;

Typography

clamp() can be used for responsive text.

font-size: clamp(1rem, 2vw, 2rem);
